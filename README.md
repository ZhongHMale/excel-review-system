# Excel审核系统

一个基于React + Node.js的Excel文件审核和数据展示系统。

## 项目结构


## 功能特性

- 📁 Excel文件上传和解析
- 📊 数据表格展示和编辑
- 📝 批注和评论功能
- 🔄 版本对比功能
- 📤 数据导出功能
- 🌐 支持中文字符处理

## 技术栈

### 前端
- React 18
- Ant Design
- React Router
- Axios
- Moment.js

### 后端
- Node.js
- Express
- SQLite3
- Multer (文件上传)
- SheetJS (Excel处理)

## 快速开始

- Node.js >= 14.0.0
- npm >= 6.0.0
